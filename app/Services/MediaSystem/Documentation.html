توثيق نظام الوسائط (Media System)

النظام الشامل لإدارة الملفات والوسائط برمجياً بكافة الاحتمالات.

💡 ملاحظة هامة (Append Mode): النظام يدعم الإضافة التلقائية؛ إذا قمت بالرفع باستخدام اسم مجلد موجود مسبقاً لنفس الموديل، فسيتم إضافة الملفات الجديدة إليه بدلاً من إنشاء مجلد جديد.
قاعدة بيانات

1- رفع صورة مع الاحتفاظ بالداتا بيز

يستخدم لربط صورة بموديل معين (مثل صورة مستخدم أو منتج).

$media = app(MediaService::class);
$user = User::find(1);

$file = $media->withResize(['thumb' => [150, 150]]) // اختياري: تصغير الصورة
              ->upload($request->file('photo'), relatable: $user, folderName: 'Avatars');

// يمكنك الوصول للرابط مباشرة
echo $file->url;
قاعدة بيانات

2- رفع ملف (PDF, ZIP, إلخ) مع الاحتفاظ بالداتا بيز

$file = app(MediaService::class)
            ->upload($request->file('cv_file'), relatable: $employee, folderName: 'Documents');

echo "اسم الملف الأصلي: " . $file->original_name;
تخزين فقط

3- رفع صورة مع عدم الاحتفاظ بالداتا بيز

يستخدم للرفع السريع دون الحاجة لسجل في قاعدة البيانات (Legacy Mode).

// تعيد هذه الدالة مسار الصورة كـ String أو مصفوفة في حال الـ Resize
$path = app(MediaService::class)
            ->withResize(['medium' => [500, 500]])
            ->uploadToStorage($request->file('logo'), folder: 'branding');

// النتيجة: uploads/branding/filename.jpg
تخزين فقط

4- رفع ملف مع عدم الاحتفاظ بالداتا بيز

$path = app(MediaService::class)
            ->uploadToStorage($request->file('backup'), folder: 'system_backups');

echo "تم الرفع في: " . $path;
قاعدة بيانات

5- رفع مجموعة صور مع الاحتفاظ بالداتا بيز

// تعيد Collection من أنواع MediaFile
$files = app(MediaService::class)
            ->withResize(['gallery' => [800, 600]])
            ->uploadMany($request->file('photos'), relatable: $product, folderName: 'Showcase');

foreach($files as $file) {
    echo $file->url;
}
تخزين فقط

6- رفع مجموعة صور مع عدم الاحتفاظ بالداتا بيز

$paths = app(MediaService::class)
            ->uploadManyToStorage($request->file('temp_images'), folder: 'temporary');

// تعيد مصفوفة من المسارات (Paths)

9- قراءة الصور والروابط

يوفر النظام قراءة ذكية تتعامل مع (Object, Path, أو fallback).

$media = app(MediaService::class);

// قراءة من Object
echo $media->url($mediaFile);

// قراءة من مسار نصي (Path)
echo $media->url('uploads/global/image.png');

// قراءة صور مع Fallsback (إذا لم توجد الصورة ترجع صورة افتراضية)
echo $media->readFile($path, size: 'thumb');
Advanced

10- الرفع على S3 (سواء صورة أو ملف)

$file = app(MediaService::class)
            ->useDisk('s3')
            ->withVisibility('private') // جعل الملف خاص (محمي)
            ->upload($request->file('secure_doc'), relatable: $user);

// سيقوم النظام تلقائياً بتوليد رابط مؤقت (Signed URL) صالح لمدة معينة
echo $file->url;

11- مسح صورة أو ملف أو مجلد كامل

$media = app(MediaService::class);

// مسح ملف واحد (من قاعدة البيانات والهارد ديسك)
$media->delete($mediaFile); 

// مسح نهائي (تجاوز الـ Soft Delete)
$media->delete($mediaFile, force: true);

// مسح مجلد كامل من الهارد ديسك
$media->deleteFolder('uploads/old_data');

12- قراءة جميع الفولدرات بالملفات

يستخدم لجلب كافة المجلدات المرتبطة بموديل معين (مثل مستخدم أو منتج) مع الملفات الموجودة بداخل كل مجلد. 

$media = app(MediaService::class);
$user = User::find(1);

// جلب المجلدات مع الملفات (Eager Loading) - افتراضي النوع 'media'
$folders = $media->getForRelatable($user, 'media');

// لجلب المرفقات فقط
$attachments = $media->getForRelatable($user, 'attachment');

foreach($folders as $folder) {
    echo "إسم المجلد: " . $folder->name;
    foreach($folder->files as $file) {
        echo " - داتا الملف: " . $file->url . " (ID: " . $file->id . ")";
    }
}

13- إنشاء مجلد وإضافة ملفات بداخله

يقوم النظام بإنشاء المجلد تلقائياً عند تحديد اسم المجلد (folderName) أثناء عملية الرفع.

$media = app(MediaService::class);

// رفع ملف واحد في مجلد جديد
$media->upload($request->file('avatar'), folderName: 'NewFolder');

// رفع ملفات متعددة في مجلد جديد
$media->uploadMany($request->file('gallery'), folderName: 'ProductGallery');

// ملاحظة: إذا كان المجلد موجوداً مسبقاً، سيتم إضافة الملفات إليه تلقائياً (Append Mode)
// دون الحاجة لأي إعدادات إضافية، فقط استخدم نفس اسم المجلد (name).

14- جلب مجلد واحد فقط مع ملفاته

يستخدم للحصول على بيانات مجلد محدد (بالاسم) مع قائمة الملفات التي بداخله لموديل معين.

$media = app(MediaService::class);
$user = User::find(1);

// جلب مجلد "الصور الشخصية" مع ملفاته (النوع الافتراضي media)
$folder = $media->getFolder($user, 'Avatars', 'media');

// جلب مجلد "العقود" من المرفقات
$contractFolder = $media->getFolder($user, 'Contracts', 'attachment');

if ($folder) {
    echo "إسم المجلد: " . $folder->name;
    foreach($folder->files as $file) {
        echo " - رابط الملف: " . $file->url . " (ID: " . $file->id . ")";
    }
}
Type System

15- التمييز بين الميديا والمرفقات (Media vs Attachment)

يمكنك الآن فصل الملفات برمجياً لكي لا تظهر المرفقات في معرض الصور والعكس، وذلك عبر استخدام الـ Type.

$media = app(MediaService::class);

// رفع صور في ميديا
$media->withType('media')->upload($file, $animal, 'Gallery');

// رفع ملف في مرفقات
$media->withType('attachment')->upload($doc, $animal, 'Contracts');

// عند القراءة، الخدمة تفلتر تلقائياً حسب النوع الممرر
$allMedia = $media->getForRelatable($animal, 'media');
$allDocs = $media->getForRelatable($animal, 'attachment');
File Management

16- مسح ملف واحد من المجلد

يمكنك الآن مسح ملف محدد باستخدام الـ ID الخاص به دون التأثير على باقي ملفات المجلد.

$media = app(MediaService::class);

// مسح ملف واحد برمجياً
$file = MediaFile::find(5);
$media->deleteFile($file);

// عبر الـ API (المسار الجديد)
// DELETE /api/v1/animals/{type}/{animal}/media/{folder}/{file_id}
// DELETE /api/v1/animals/{type}/{animal}/attach/{folder}/{file_id}
