نظرة عامة — كيف يحميك النظام؟

كل طلب (Request) يمر عبر 11 طبقة حماية متتالية. إذا فشل في أي طبقة يتم رفضه فوراً وتسجيله في قاعدة البيانات.

Request → [1] IP Filter → [2] Rate Limit → [3] Force JSON → [4] Payload Size
        → [5] Security Headers → [6] CORS → [7] API Key → [8] Timestamp
        → [9] HMAC Signature → [10] Nonce → [11] Threat Detection → ✅ Controller

طبقات الحماية

🚫

فلتر IP

يمنع عناوين IP المشبوهة أو المحظورة من الوصول. يدعم القائمة البيضاء والسوداء.

⏱️

تحديد المعدل

يمنع الإساءة بتقييد عدد الطلبات لكل IP (افتراضي: 60 طلب/دقيقة).

🔑

مفتاح API

كل عميل يحصل على مفتاح فريد. يُرسل في الهيدر X-API-Token. يدعم التشفير AES-256.

✍️

التوقيع HMAC

يضمن أن الطلب لم يتم تعديله. التوقيع = HMAC-SHA256(METHOD|URL|TIMESTAMP|BODY, secret)

🔒

حماية Nonce

جديد

رموز استخدام لمرة واحدة تمنع إعادة تشغيل الطلبات حتى لو تم اعتراضها.

🧠

كشف التهديدات

جديد

نظام تسجيل ذكي (0-100) يقيّم خطورة كل طلب ويحظر التهديدات العالية تلقائياً.

كشف التهديدات التكيّفي

يحسب درجة خطورة (0-100) لكل طلب بناءً على عدة إشارات:

الإشارة النقاط الوصف
أحداث أمنية سابقة +30 عدد الأحداث الأمنية لهذا الـ IP خلال ساعة
User-Agent مشبوه +40 أدوات مثل sqlmap, nikto, nmap, burp
قرب من حد المعدل +15 إذا استهلك أكثر من 70% من الحد المسموح
هيدرات مفقودة +10 User-Agent مفقود أو قصير جداً
مسار مشبوه +5 طلبات مثل .env, wp-admin, phpmyadmin

< 25

منخفض — بدون إجراء

25 – 79

متوسط — تسجيل تحذير

≥ 80

عالي — حظر تلقائي

حماية Nonce (انتقائية)

رمز يُستخدم مرة واحدة فقط. يمنع إعادة تشغيل الطلبات (Replay Attack). النظام الآن ذكي: يتم التحقق فقط في العمليات الحساسة (Critical).

✅ يُشترط Nonce لـ:

  • جميع عمليات الكتابة (POST, PUT, DELETE)
  • مسارات الدفع (api/v1/payments/*)
  • مسارات الطلبات (api/v1/orders/*)
  • أو أي مسار يتم تعريفه يدوياً كـ "حساس"

⏭️ يتم التجاوز لـ:

  • عمليات القراءة (GET)
  • مسارات الهوية (Login, Register, Auth)
  • مسارات المعلومات العامة

سير العمل (Workflow):

  1. العميل يطلب nonce في العمليات الحساسة فقط عبر GET /security/nonce.
  2. يتم إرسال الـ nonce في هيدر X-NONCE.
  3. إذا كان المسار غير حساس (مثل جلب قائمة المنتجات عبر GET)، يتم التجاوز لتسريع الاستجابة.

تكامل Vue.js

1. إنشاء Security Service

// src/services/SecurityService.js
import axios from 'axios';

const API_BASE = import.meta.env.VITE_API_URL;

class SecurityService {
  constructor() {
    this.apiKey = import.meta.env.VITE_API_KEY;
    this.secret = import.meta.env.VITE_API_SECRET;
  }

  // ─── إنشاء الهيدرات الأمنية ───
  getSecurityHeaders(method, url, body = '') {
    const timestamp = Math.floor(Date.now() / 1000).toString();
    const payload = `${method.toUpperCase()}|${url}|${timestamp}|${body}`;

    // HMAC-SHA256 signature
    const signature = CryptoJS.HmacSHA256(payload, this.secret).toString();

    return {
      'X-API-Token': this.apiKey,
      'X-TIMESTAMP': timestamp,
      'X-SIGNATURE': signature,
      'Content-Type': 'application/json',
      'Accept': 'application/json',
    };
  }

  // ─── جلب Nonce (إن كانت مفعّلة) ───
  async getNonce() {
    const url = `${API_BASE}/api/v1/security/nonce`;
    const headers = this.getSecurityHeaders('GET', url);
    const { data } = await axios.get(url, { headers });
    return data.data.nonce;
  }

  // ─── طلب آمن مع Nonce ───
  async secureRequest(method, path, body = null) {
    const url = `${API_BASE}${path}`;
    const bodyStr = body ? JSON.stringify(body) : '';
    const headers = this.getSecurityHeaders(method, url, bodyStr);

    // إضافة Nonce إن كانت مفعّلة
    try {
      const nonce = await this.getNonce();
      headers['X-NONCE'] = nonce;
    } catch (e) { /* Nonce غير مفعّلة */ }

    return axios({ method, url, headers, data: body });
  }
}

export default new SecurityService();

2. استخدام في Vue Component

<script setup>
import security from '@/services/SecurityService';
import { ref } from 'vue';

const orders = ref([]);

async function loadOrders() {
  const { data } = await security.secureRequest('GET', '/api/v1/orders');
  orders.value = data.data;
}

async function createOrder(orderData) {
  const { data } = await security.secureRequest('POST', '/api/v1/orders', orderData);
  orders.value.push(data.data);
}
</script>

تكامل Flutter

1. إضافة التبعيات

# pubspec.yaml
dependencies:
  http: ^1.1.0
  crypto: ^3.0.3

2. Security Service

// lib/services/security_service.dart
import 'dart:convert';
import 'package:crypto/crypto.dart';
import 'package:http/http.dart' as http;

class SecurityService {
  final String apiKey;
  final String secret;
  final String baseUrl;

  SecurityService({
    required this.apiKey,
    required this.secret,
    required this.baseUrl,
  });

  // ─── HMAC-SHA256 Signature ───
  String _generateSignature(String method, String url, String ts, String body) {
    final payload = '${method.toUpperCase()}|$url|$ts|$body';
    final hmac = Hmac(sha256, utf8.encode(secret));
    return hmac.convert(utf8.encode(payload)).toString();
  }

  // ─── بناء الهيدرات الأمنية ───
  Map<String, String> _buildHeaders(String method, String url, {String body = ''}) {
    final ts = (DateTime.now().millisecondsSinceEpoch ~/ 1000).toString();
    final sig = _generateSignature(method, url, ts, body);
    return {
      'X-API-Token': apiKey,
      'X-TIMESTAMP': ts,
      'X-SIGNATURE': sig,
      'Content-Type': 'application/json',
      'Accept': 'application/json',
    };
  }

  // ─── جلب Nonce ───
  Future<String?> _getNonce() async {
    try {
      final url = '$baseUrl/api/v1/security/nonce';
      final headers = _buildHeaders('GET', url);
      final res = await http.get(Uri.parse(url), headers: headers);
      if (res.statusCode == 200) {
        return jsonDecode(res.body)['data']['nonce'];
      }
    } catch (_) {}
    return null;
  }

  // ─── GET آمن ───
  Future<http.Response> secureGet(String path) async {
    final url = '$baseUrl$path';
    final headers = _buildHeaders('GET', url);
    final nonce = await _getNonce();
    if (nonce != null) headers['X-NONCE'] = nonce;
    return http.get(Uri.parse(url), headers: headers);
  }

  // ─── POST آمن ───
  Future<http.Response> securePost(String path, Map<String, dynamic> body) async {
    final url = '$baseUrl$path';
    final bodyStr = jsonEncode(body);
    final headers = _buildHeaders('POST', url, body: bodyStr);
    final nonce = await _getNonce();
    if (nonce != null) headers['X-NONCE'] = nonce;
    return http.post(Uri.parse(url), headers: headers, body: bodyStr);
  }
}

الهيدرات المطلوبة في كل طلب

الهيدر مطلوب؟ مثال
X-API-Token ✅ دائماً a1b2c3d4e5f6...
X-TIMESTAMP ⚡ إذا مفعّل 1712995200
X-SIGNATURE ⚡ إذا مفعّل HMAC-SHA256 hash
X-NONCE ⚡ إذا مفعّل من /security/nonce
Content-Type ✅ POST/PUT application/json
